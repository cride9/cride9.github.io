## Context
CrideLLMApi represents a transition from consuming AI APIs to engineering the infrastructure around them.

## My contribution
The abstraction covers OpenAI-compatible chat completions, embeddings, and model endpoints, with strongly typed DTOs and asynchronous generation.

## Streaming and execution
SSE streaming, context management, function/tool calling, typed tool arguments, tool execution, and agent loops form the execution layer.

## Local providers
Local model providers and llama.cpp integration support experiments with custom agentic execution. The focus is explicit contracts across generation, tool use, and application control flow.
