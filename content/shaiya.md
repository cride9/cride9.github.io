## Context
Running a Shaiya MMORPG private server brings application development and infrastructure operation into the same system.

## My contribution
The work covers the game server, client management, website, backend, database, update and patch infrastructure, deployment, and administration.

## Reliability and protection
Networking, IP protection, and DDoS mitigation are part of the operating architecture. The server has repeatedly been targeted by DDoS attacks; so far, the protection architecture has prevented those attempts from causing meaningful disruption.

## Engineering focus
The system must remain understandable across boundaries: client distribution, application services, storage, and network protection. Reliability is an ongoing operational responsibility.
